# Delhi pilot data sources

Access and licensing details below were checked against the linked provider
documentation on **19 October 2026**. The pilot bbox is a 5 km square centered
near DTU, Rohini (28.7501° N, 77.1177° E); the downloader records its exact
UTM-derived WGS84 bounds in `data/raw/manifest.json`.

| Source | Access method and current access rules | License / attribution | Spatial and temporal resolution | Fallback |
|---|---|---|---|---|
| **Open-Meteo** | Call the public Forecast API over HTTPS with latitude/longitude and requested hourly variables. No API key is required for the free endpoint. It is limited to non-commercial use, up to 10,000 calls/day, and has no uptime guarantee; commercial use requires a paid plan/API key. | API data are **CC BY 4.0**. Attribute Open-Meteo and indicate modifications; link to its licence. | Model grid resolution varies by selected weather model (roughly 1–25 km); the API interpolates output to the requested point. Hourly forecast, up to 7 days in the pilot script. | India Meteorological Department (IMD) forecasts/observations where available; ERA5 via Copernicus Climate Data Store for retrospective analysis (coarser than neighborhood scale). |
| **Landsat 8/9 Collection 2 Level-2 land-surface temperature (Earth Engine)** | Use `LANDSAT/LC08/C02/T1_L2` and `LANDSAT/LC09/C02/T1_L2` in Earth Engine; select `PROCESSING_LEVEL=L2SP` and `ST_B10`. Earth Engine requires a Google account, a registered Cloud project with the Earth Engine API enabled, and one-time local authentication (`earthengine authenticate`). Non-commercial research access is available subject to Earth Engine's current eligibility and terms. | Landsat data from USGS/NASA are U.S. government data and generally public domain; acknowledge USGS/NASA and the Earth Engine dataset. Check dataset-specific attribution/terms for derived products. | Earth Engine catalog pixel grid: **30 m**; thermal instrument measurements have **100 m native resolution** and are resampled to that grid. Daytime scenes only; clear-sky gaps and missing ST retrievals occur. Pilot output is annual-median °C. | MODIS MOD11A1 daily LST at 1 km for more frequent, coarser coverage; ECOSTRESS LST where available for finer spatial detail but less regular coverage. |
| **Sentinel-2 L2A surface reflectance / NDVI (Earth Engine)** | Use the harmonized `COPERNICUS/S2_SR_HARMONIZED` collection in Earth Engine. The pilot computes NDVI from B8 (NIR) and B4 (red), masking cloud/shadow classes using SCL. Earth Engine project and authentication requirements are the same as above. Copernicus Data Space also provides Sentinel data directly through its catalog and APIs; direct downloads require user registration. | Copernicus Sentinel data are free and open under the **Copernicus Sentinel Data Legal Notice**; provide source attribution and do not imply endorsement. | B4 and B8 are **10 m**; revisit is about 5 days at the equator (actual clear-sky observations vary). Pilot output is an annual-median NDVI composite. | Landsat 8/9 surface reflectance NDVI at 30 m; expect lower spatial detail and fewer clear observations. |
| **OpenStreetMap via OSMnx** | `osmnx.features_from_bbox` queries tagged features from public Overpass API infrastructure; no account is required. Public instances are shared and usage-limited, so use a small bbox, cache results, and retry later rather than issuing repeated requests. | **Open Database License (ODbL) 1.0**. Attribute “© OpenStreetMap contributors”, link to <https://www.openstreetmap.org/copyright>, and comply with attribution and share-alike obligations for adapted databases. | Vector features (not a fixed raster resolution); completeness and positional detail vary by feature and local mapping. Snapshot date is the download date. | Download a regional India OSM PBF extract from Geofabrik and query it locally with OSMnx/osmium; the same ODbL terms apply. |
| **WorldPop population counts** | For the pilot script, download the India 2020 1 km GeoTIFF from the WorldPop data archive, then crop it locally to the pilot bbox. The file is a public direct download and needs no API key. The archive index does not state file-level licence terms; verify the specific product terms before redistribution or commercial use. | **No explicit licence is stated in the linked archive index.** Retain WorldPop attribution/citation and confirm the applicable product terms before redistribution or commercial use. | The selected product is **30 arc-seconds (~1 km at the equator)**, WGS84; it estimates people per grid cell. The script uses the 2020 estimate, not a real-time count. WorldPop also publishes finer 3-arc-second (~100 m) products, but the 1 km country raster is smaller and convenient for this pilot. | GHSL population grids (GHS-POP) from the European Commission JRC, or official Census of India/municipal ward population counts where a gridded product is not required; document their different reference years and resolutions. |
